## 6. 명따라 관련 응대 문구

### 6-1. 명따라가 무엇인지 묻는 경우

```
명따라는 아이의 생년월일시를 바탕으로 성향을 참고해보고, 관심 직업과 부모 대화의 출발점을 찾아보는 콘텐츠입니다.

진로를 결정하거나 적성을 확정하는 기능이 아니라, 부모와 아이가 함께 이야기해볼 수 있는 참고 자료로 활용해 주세요.
```

### 6-2. 사주로 직업을 맞히는지 묻는 경우

```
명따라는 사주로 아이의 직업을 맞히거나 진로를 결정하는 서비스가 아닙니다.

아이의 성향을 가볍게 참고하고, 어떤 관심 분야를 함께 살펴보면 좋을지 대화의 실마리를 제공하는 콘텐츠입니다.
```

### 6-3. 명따라 결과가 맞지 않는다고 하는 경우

```
명따라는 재미·참고용 콘텐츠이며, 아이의 성향이나 진로를 단정하지 않습니다.

결과가 아이와 다르게 느껴진다면 "이 부분은 우리 아이와 다르네", "이 부분은 조금 비슷하네"처럼 부모와 아이가 대화해보는 자료로 활용해 주세요.
```

### 6-4. 생년월일시를 잘못 입력한 경우

```
생년월일시를 잘못 입력한 경우 결과가 달라질 수 있습니다.

현재 수정 기능 제공 여부를 확인해야 하므로, 아래 정보를 보내주세요.

1. 가입 이메일
2. 자녀 이름 또는 닉네임
3. 잘못 입력한 항목
4. 수정이 필요한 내용

확인 후 안내드리겠습니다.
```
