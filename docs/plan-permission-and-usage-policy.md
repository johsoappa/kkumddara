## 7. 명따라 사용량 정책

### 현재 베타 기준

- Free 플랜: 명따라 **1회 체험** 가능
- `myeonddara_usage` 테이블: `child_id + year` 기준 사용량 관리 구조 존재
- `myeonddara_yearly_limit` 기준으로 연간 사용 횟수 관리
- 현재 Phase 2: **비활성 상태** (`NEXT_PUBLIC_MYEONDDARA_PHASE2_ENABLED` 미설정)
- 현재 `MYEONDDARA_PHASE2_DEDUCT_USAGE=false`: 베타 기간 사용량 차감 유예 가능
- 결제 기능 미오픈 상태이므로 베타 기간 사용량 차감 정책은 탄력적으로 운영

| Premium 플랜 연간 명따라 횟수 | 미확정 |
| Family 플랜 자녀별 연간 횟수 | 미확정 |
| Family Plus 플랜 자녀별 연간 횟수 | 미확정 |

### 명따라 핵심 포지션

명따라는 아이의 성향을 참고해 진로 대화를 시작할 수 있도록 돕는 **참고용 성향 리포트**다.
진로를 확정하거나 미래를 예측하는 기능이 아니다.

## 8. AI 진로 상담 사용량 정책

### AI 상담 안내 기준

- 아이의 관심사와 활동 기록을 바탕으로 **대화형 진로 탐색을 돕는 보조 기능**
- 결과는 **참고용**이며 진로 결정이나 학업 성취를 보장하지 않음
- 학부모와 자녀의 진로 대화를 돕는 목적으로 제공
- 아이의 미래를 예측하거나 확정하는 기능이 아님
- AI 진로 상담은 꿈따라의 중심 기능이 아닌 보조 기능임

### 현재 베타 기준

- 현재 `AI_CONSULT_ENABLED=true` (베타 활성 상태)
- 베타 기간 무료 상담: 월 N회 (현재 3회 기준, 코드 `FREE_LIMIT=3`)
- 초과 시: "이번 달 준비된 무료 맞춤 상담을 모두 사용했어요." 안내

### 정식 오픈 전 확정 필요

| 항목 | 현재 상태 |
|---|---|
| Free 플랜 AI 상담 제공 여부 | 미확정 (베타 기간 제한 제공 중) |
| Basic 플랜 월간 또는 일간 상담 횟수 | 미확정 |
| Premium 이상 확장 횟수 | 미확정 |
| Family 플랜 자녀별 횟수 | 미확정 |
| 남용 방지 Rate Limiting 기준 | 미확정 |
| 상담 기록 저장 범위 | 미확정 |

## 9. 부모 주간 리포트 권한 정책

### 부모 주간 리포트 제공 목적

- 아이가 어떤 직업과 활동에 관심을 보였는지 확인
- 부모와 자녀의 **진로 대화를 돕는 자료** 제공
- 주간 단위 활동 흐름을 가볍게 정리
- 아이를 **평가하기 위한 자료가 아니라 대화를 돕기 위한 자료**
- 성적 평가나 진로 판정 기능이 아님

### 현재 베타 기준

- 현재 베타 기간에 플랜 구분 없이 제한 제공
- `weekly_activity_completions` 테이블 기반 추천 활동 완료 저장 (migration 046 적용 완료 여부 OZ 확인 필요)
- "현재 베타 운영 중입니다" 배지 표시

### 정식 오픈 전 확정 필요

| 항목 | 현재 상태 |
|---|---|
| Free 플랜 제공 여부 | 미확정 |
| Basic 플랜 제공 범위 | 미확정 |
| Premium 이상 차별점 (더 상세한 분석 등) | 미확정 |
| Family 플랜에서 자녀별 리포트 제공 방식 | 미확정 |
| 리포트 생성 주기 (주간 고정 여부) | 미확정 |

## 10. Free 플랜 체험 정책

### Free 플랜의 목적

Free 플랜은 사용자가 꿈따라의 핵심 흐름을 이해할 수 있도록 제공되는 **제한 체험 플랜**이다.

### 핵심 체험 범위

- 자녀 1명 등록
- 직업 탐색 (`/explore`) 무제한
- 관심 운동 기반 탐색 (`/explore/interests/sports`) 무제한
- 로드맵 미션 확인 및 체크
- 명따라 **1회** 체험
- 베타 기간 중 일부 부모 기능 제한 체험 (주간 리포트, AI 상담)

Free 플랜은 정식 유료 기능을 모두 제공하는 플랜이 아니다.

### 정식 오픈 전 확정 필요

- Free 플랜의 정식 오픈 후 제공 범위 최종 확정
- 베타 종료 후 Free 플랜 사용자의 기존 데이터 처리 기준
- Free → 유료 전환 시 혜택 안내 기준

## 11. 베타 기간 예외 정책

### 베타 기간 운영 기준

- 현재 베타 기간에는 **유료 결제가 발생하지 않는다.**
- 일부 기능은 정식 플랜 정책과 다르게 무료 또는 제한 제공될 수 있다.
- 명따라 사용량 차감은 베타 정책에 따라 유예될 수 있다. (`MYEONDDARA_PHASE2_DEDUCT_USAGE=false`)
- AI 상담은 **참고용 베타 기능**으로 제공된다.
- 베타 기간 중 수집된 피드백을 바탕으로 정식 오픈 전 플랜 정책을 조정할 수 있다.

### 베타 기간 주의사항

- 베타 제공 범위가 정식 오픈 후 **그대로 유지된다는 의미는 아니다.**
- 결제 기능 오픈 전에는 환불 정책보다 **무료 베타 운영 기준을 우선** 적용한다.
- 사용자에게는 **"베타 기간 무료 이용 · 자동결제 없음"** 기준으로 안내한다.
- 명따라 Phase 2는 베타 기간 중 활성화하지 않는다.

### 베타 → 정식 오픈 전환 시 변경해야 할 사항

| 항목 | 변경 방향 |
|---|---|
| `MYEONDDARA_PHASE2_DEDUCT_USAGE` | `false` → `true` 전환 (별도 작업지시서 필요) |
| 명따라 Phase 2 활성화 | `NEXT_PUBLIC_MYEONDDARA_PHASE2_ENABLED=true` (별도 확인 필요) |
| 결제 연동 | 별도 결제 기능 구현 작업 필요 |
| 플랜별 사용량 제한 로직 구현 | 별도 작업지시서 필요 |
| Free 플랜 제공 범위 코드 반영 | 별도 작업지시서 필요 |

아래 문구는 복붙 가능한 초안이다. 정식 오픈 전 최종 검토 후 확정한다.

### 명따라 사용량 초과 안내

```

```

### 자녀 수 제한 안내

```
현재 플랜에서 등록할 수 있는 자녀 수를 초과했어요.
더 많은 자녀를 등록하려면 Family 또는 Family Plus 플랜이 필요합니다.
```

### AI 상담 사용량 초과 안내

```
이번 달 준비된 무료 맞춤 상담을 모두 사용했어요.
아이의 관심 직업과 로드맵 활동은 계속 확인할 수 있습니다.
```

### 공동 양육자 초대 제한 안내

```
현재 플랜에서는 공동 양육자 초대 기능이 제한되어 있어요.
정식 오픈 후 플랜에 따라 초대 가능 범위가 안내될 예정입니다.
```

### 베타 기간 안내

```
현재 꿈따라는 베타 운영 단계로, 일부 기능은 무료로 제공되거나
사용량 정책이 정식 오픈 전까지 달라질 수 있습니다.
```

### 결제 기능 미오픈 안내

```
현재 꿈따라는 정식 결제 기능 오픈 전입니다.
베타 기간 동안은 자동 결제가 발생하지 않습니다.
```

### 기술 구현 주의사항

- 자녀 수 초과 판단: `child` 테이블 count + 플랜 limit 비교 로직 필요
- 명따라 사용량: `myeonddara_usage` 테이블 + `myeonddara_yearly_limit` 기반 차감 로직 정확성 확인 필요
- AI 상담 사용량: `ai_consult_usage` 구조 정확성 확인 필요 (월간 리셋 기준 확인)
- 공동 양육자: `caregiver_invite` 테이블 구조 확인 후 초대 권한 로직 설계 필요
- 플랜 변경 시 기존 데이터 처리: 다운그레이드 → 초과 자녀 데이터 처리 기준 확정 필요

### 문구 작성 주의사항

아래 표현은 플랜 관련 UI/UX 문구에 사용하지 않는다:

- ❌ 합격 보장, 진로 확정, 성공 보장
- ❌ 아이의 미래를 예측
- ❌ 성적 향상 보장, 입시 결과 보장
- ❌ 선수가 못 되면, 실패하면, 대체 직업
- ❌ AI가 정답을 알려준다
- ❌ 아이의 적성을 확정한다

꿈따라 표현 기준:

```
아직 꿈이 정해지지 않아도 괜찮아요.
좋아하는 것에서 직업을 찾아요.
```
