## 1. 문서 목적

- OZ가 실제 운영 도메인에서 베타 운영 전 최종 수동 점검을 수행하기 위한 체크리스트 제공
- 체크 결과를 PASS / FAIL / 확인 필요 / 보류로 기록
- 발견 이슈를 P0 / P1 / P2로 분류해 즉시 대응 여부 결정
- 베타 운영 가능 최종 판정 기준 제공

## 3. 확인 결과 표기 기준

각 항목은 아래 기준으로 기록한다.

| 상태 | 의미 |
|---|---|
| PASS | 의도한 대로 정상 동작하거나 문구가 정상 표시됨 |
| FAIL | 기능 오류, 화면 깨짐, 잘못된 문구 등 즉시 수정이 필요한 문제 발견 |
| 확인 필요 | 코드상 판단이 어렵거나 실제 사용자 환경에서 추가 확인이 필요한 항목 |
| 보류 | 현재 베타 범위가 아니거나 정식 오픈 전 확정 예정인 항목 |

기록 예시:

| 확인 항목 | 결과 | 메모 |
|---|---|---|
| 꿈따라.kr 접속 | PASS | 모바일 Chrome 정상 |
| 명따라 진입 | 확인 필요 | 로그인 계정 기준 추가 확인 필요 |
| 공동 양육자 초대 | 보류 | 베타 기간 비활성 |

## 20. P0 / P1 / P2 분류 기준

### P0 — 즉시 수정 필요

아래 항목이 발견되면 베타 운영을 보류하고 즉시 수정 작업지시서를 작성한다.

- 운영 도메인 접속 불가
- 로그인 또는 회원가입 불가
- 주요 페이지 500 오류
- 개인정보 노출 의심
- 결제 기능 미오픈 상태인데 결제가 발생하는 것처럼 보임
- 자동결제 없음 정책과 정면 충돌하는 문구 노출
- 모바일에서 핵심 버튼 클릭 불가
- 명따라 또는 AI 상담 결과가 위험하거나 부적절하게 표시됨

### P1 — 베타 운영 전 수정 권장

아래 항목은 가능하면 베타 운영 전 수정한다.

- 학부모 체험 또는 학생 체험 흐름이 헷갈림
- 주요 CTA 문구가 부정확함
- 명따라 / AI 상담 / 부모 리포트 설명이 정책과 약하게 충돌함
- 직업 탐색 검색 결과가 명백히 이상함
- 모바일에서 일부 카드가 깨짐
- 문의 채널 연결 오류

### P2 — 베타 운영 중 누적 개선

아래 항목은 베타 운영 중 피드백을 보며 개선한다.

- 카드 간격 개선
- FAQ 추가

- 로드맵 미션 예시 보강
- 요금제 설명 보강
