# 꿈따라 가격·B2C 부가상품 정책 요약 v2.5

> 최종 업데이트: 2026-06-08
> 이 문서는 v2.5 기준 가격 페이지 UI/카피 정책을 정리한 참고 문서입니다.
> 결제 구현 완료 기준이 아니며, 실제 결제 기능은 PG사 확정 후 별도 작업합니다.

## 1. v2.5 가격 페이지 기준

### 1-1. 헤드라인 카피
```
아이의 관심이 진로 대화로 이어지도록
아이의 관심은 무료로 가볍게 살펴볼 수 있습니다.
꿈따라는 부모와 아이가 함께 직업을 살펴보고,
작은 미션을 실천하며, 변화를 기록하는 진로 탐색 서비스입니다.
```

### 1-2. 3개 티어 구조

| 티어 | 가격 (월 / 연) | 상태 | CTA |
|---|---|---|---|
| Seed 무료 | ₩0 | 시작 가능 | 무료로 시작하기 |
| Sprout 베이직 | 월 ₩5,900 / 연 ₩59,000 | 베타 추천 | 베이직 준비 중 (비활성) |
| Compass 프리미엄 | 월 ₩11,900 / 연 ₩119,000 | 오픈 예정 | 프리미엄 오픈 예정 (비활성) |

## 2. 단건 상품 섹션 기준

### 2-1. 위치
3개 티어 카드 아래, "왜 유료인가" 섹션 위.

```
[헤드라인]
  ↓
[3개 티어 카드]
  ↓
[구독 전 입문 상품 / 단건 상품 섹션]
  ↓
[왜 유료인가]
  ↓
[FAQ]
```

### 2-2. 단건 상품 목록

| 상품명 | 가격 | CTA | 상태 |
|---|---|---|---|
| 꿈따라 진로 리포트 PDF | ₩3,900 | PDF 리포트 준비 중 (비활성) | 출시 예정 |
| 명따라 진로 성향 리포트 | ₩6,900 | 명따라 단건 준비 중 (비활성) | 출시 예정 |

## 3. 단건 상품 디자인 위계

- 단건 카드는 티어 카드 대비 약 60~70% 높이의 서브 카드로 표시
- 티어 카드: 3열 메인 카드
- 단건 카드: 가로 2열 서브 카드
- 단건 섹션 배경: 옅은 회색(`#F9FAFB`) 또는 베이지 톤
- "구독 전 입문 상품"은 **eyebrow text** (H3 제목이 아닌 작은 라벨/캡션 스타일)
- 의미 위계상 메인 제목은 "구독 전, 필요한 리포트만 먼저 경험해보세요"

## 5. AI 상담 카운팅 기준

- **1회 = 부모가 보낸 메시지 1건**
- AI의 답변은 별도 차감 없음
- 예시: "아이가 축구를 좋아하는데 어떤 직업을 함께 볼 수 있나요?" → 1회 차감

| 티어 | 월 AI 상담 횟수 |
|---|---|
| Seed 무료 | 3회 |
| Sprout 베이직 | 20회 |
| Compass 프리미엄 | 100회 |

---

## 6. 명따라 고지 기준

- 명따라는 **재미·참고용 콘텐츠**임을 항상 병기
- 금지 표현:
  - "명따라가 진로를 맞힙니다"
  - "사주가 맞습니다"
  - "명따라 무제한 확정"
  - "명따라 심층 분석 상세 범위 확정"
- 허용 표현:
  - "재미·참고용 콘텐츠입니다"
  - "명따라 심층 제공 예정"
  - "베이직 1회 체험, 프리미엄 심층 제공 예정"
  - "부모와 아이가 대화를 시작할 때 도움이 되는 또 다른 관점"
