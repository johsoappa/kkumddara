## 1. 서비스 한 줄 정의

꿈따라는 자녀의 관심사와 성향을 바탕으로 직업 탐색, 진로 로드맵, 주간 실천 미션을 연결해주는 학부모·학생 대상 진로 설계 서비스다.

---

## 2. 서비스 개요

꿈따라는 학부모와 학생이 함께 사용하는 진로 탐색 서비스로, 아이가 막연하게 느끼는 진로 고민을 구체적인 탐색 경험으로 전환하는 것을 목표로 한다.

- **아이의 관심사와 성향을 출발점으로** 직업 탐색 및 관련 직업 생태계 제공
- **직업별 로드맵과 주간 미션**을 통해 탐색 이후 실행 가능한 진로 경험 제공
- **명따라**를 통해 만세력 기반 성향 참고 리포트 제공 (학부모와 자녀의 진로 대화 시작점)
- **관심 운동 기반 진로 탐색**처럼 아이의 실제 흥미를 직업 생태계와 연결
- **AI 진로 상담 기능**으로 학부모가 자녀 진로 관련 질문에 답을 찾을 수 있는 대화형 보조 도구 제공
- **부모 주간 리포트**를 통해 자녀의 진로 탐색 진행 상황 확인 및 주간 미션 관리
- 현재 **베타 서비스 단계**에서 기능 검증 및 사용성 개선 중

---

## 3. 해결하려는 문제

### 3-1. 현재 학부모·학생이 겪는 진로 탐색의 어려움

- 초등·중학생 시기 진로 탐색이 막연하고 구체적인 방향을 찾기 어려움
- 학부모가 자녀의 관심사를 어떻게 진로와 연결해야 할지 실마리를 찾기 어려움
- 직업 정보가 단순 나열에 그쳐 아이의 흥미와 연결되지 않는 경우가 많음
- 아이가 좋아하는 활동(스포츠, 예술, 게임 등)과 실제 직업 세계가 연결되어 있지 않음
- 진로 탐색 후 실천 단계로 이어지지 않아 탐색이 일회성으로 끝남
- 학원·학교·가정에서 활용 가능한 가벼운 진로 도구가 부족함

### 3-2. 꿈따라의 해결 방식

꿈따라는 단순 직업 정보 제공을 넘어, 아이가 좋아하는 활동과 성향을 기반으로 탐색 가능한 직업군을 제안하고, 주간 미션과 로드맵을 통해 작은 실행으로 이어지도록 설계되어 있다.

## 4. 핵심 사용자

| 사용자 | 주요 니즈 |
|---|---|
| 초등학생·중학생 | 흥미 기반으로 다양한 직업을 쉽게 탐색하고 싶음 |
| 학부모 | 자녀의 관심사와 성향을 이해하고 진로 대화를 시작하고 싶음 |

| 학원·교육기관 | 학생별 관심사 기반 상담 자료로 활용하고 싶음 |
| 지자체·공공기관 | 청소년 진로 탐색 지원 프로그램에 활용할 서비스가 필요함 |

## 6. 기능별 상세 현황

### 6-1. 직업 탐색 기능

- **구현 상태**: 구현 완료
- **사용자 대상**: 학생, 학부모 모두 사용 가능
- **주요 화면**: `/explore` — 검색 + 카테고리 필터 + 직업 카드 리스트
- **주요 특징**:
  - 기본 목록은 대표 직업 중심으로 표시
  - 검색어 입력 시 세부 직업도 결과에 포함되어 탐색 범위 확장
  - 좋아요 기능으로 관심 직업 저장 (로그인 시 DB 연동, 비로그인 시 로컬 저장)
  - 스포츠 관련 검색어 입력 시 관심 운동 진로 탐색 CTA 자동 안내
- **주요 가치**: 학생이 관심 분야 키워드나 직업명으로 직접 탐색 가능
- **사업계획서 활용 포인트**: 대표 직업 100개 + 세부 직업 검색 구조를 통해 아이의 관심사에서 시작하는 직업 탐색 경험 제공
- **확인 파일**: `src/app/explore/page.tsx`

### 6-2. 대표 직업 100개 확장

- **구현 상태**: 구현 완료
- **사용자 대상**: 서비스 전체 사용자
- **주요 특징**:
  - occupation_master 기준 대표 직업 100개 + 세부 직업 14개 = 총 114개 관리
  - IT·기술, 의료·보건, 교육, 예술·미디어, 사회·공공, 스포츠 등 다양한 직업군 포함
  - 베타 기준 직업 데이터 기반 마련 완료
- **사업계획서 활용 포인트**: 광범위한 직업 데이터를 기반으로 아이의 다양한 관심사와 연결 가능한 직업 생태계 구축
- **확인 파일**: `docs/occupation-100-expansion-plan.md`

### 6-3. 세부 직업 검색 구조

- **구현 상태**: 구현 완료
- **주요 특징**:
  - 기본 목록: 대표 직업 중심 표시
  - 검색어 입력 시: 세부 직업(is_representative=false)도 검색 결과에 포함
  - 공백 정규화 검색 지원 ("물류관리사" ↔ "물류 관리사" 매칭)
  - 사용자가 직업이 없다고 느끼는 문제를 완화
- **사업계획서 활용 포인트**: 관심 직업을 다양한 방식으로 찾을 수 있는 유연한 탐색 구조

### 6-4. 관심 운동 기반 진로 탐색

- **구현 상태**: 구현 완료
- **사용자 대상**: 학생, 학부모
- **주요 화면**: `/explore/interests/sports`
- **주요 특징**:
  - 축구, 야구, 농구, 배구, 수영, 태권도, 줄넘기, 골프, e스포츠, 아웃도어 10개 운동 제공
  - 아이가 좋아하는 운동을 선택하면 연결된 직업군과 그 이유 안내
  - 직업 상세 페이지 바로 이동 가능
  - DB 없음 / API 없음 / 정적 데이터 기반 — 빠르고 안정적
  - 명따라 결과 화면에서도 CTA로 연결 (2026-05-27 추가)
- **주요 가치**: 선수가 되는 것만이 스포츠 관련 진로가 아님을 보여주고, 스포츠 산업 생태계의 다양한 직업을 탐색 가능
- **사업계획서 활용 포인트**: 아이가 좋아하는 운동을 출발점으로 직업 세계를 넓히는 차별화된 진로 탐색 경험
- **확인 파일**: `src/app/explore/interests/sports/page.tsx`, `src/data/sportsInterestData.ts`

### 6-5. 스포츠 진로 생태계 직업

- **구현 상태**: P1 5개 로드맵 직접 구현 완료, P2 5개 fallback 유지
- **P1 구현 완료 (smoke test PASS)**:
  - 스포츠 데이터 분석가
  - 유소년 스포츠 지도자
  - 스포츠 콘텐츠 기획자
  - 운동처방사
  - 스포츠 안전관리자
- **P2 fallback 유지 (직접 로드맵 미구현)**:
  - 스포츠 테크 개발자
  - 스포츠 마케터
  - 수상안전요원
  - 아웃도어 레저 기획자
  - 해양레저 전문가
- **주의**: P2 5개는 현재 일반 fallback 화면 유지 상태이며, 직접 로드맵은 아직 구현되지 않았음
- **사업계획서 활용 포인트**: 스포츠 관련 직업을 선수 중심이 아닌 산업 생태계 관점으로 제시하는 차별화된 직업군 구성
- **확인 파일**: `src/data/roadmaps.ts`, `docs/sports-ecosystem-weekly-roadmap-decision.md`

### 6-6. 직업 상세 페이지

- **구현 상태**: 구현 완료
- **주요 화면**: `/explore/[id]`
- **주요 특징**:
  - 직업 설명, 관심 분야 정보 제공
  - 로드맵 바로 이동 흐름
  - 관심 운동 기반 연관 직업 섹션(SportsInterestCareerSection) 표시 — 스포츠 관련 직업은 연결 직업 탐색 가능
- **사업계획서 활용 포인트**: 하나의 직업을 탐색하면 연관 직업 생태계로 자연스럽게 탐색 범위가 확장되는 구조

### 6-7. 직업별 로드맵

- **구현 상태**: 구현 완료 (73개 직업 로드맵)
- **주요 화면**: `/roadmap/[occupationId]`
- **주요 특징**:
  - 3단계 구조 (현재 단계 → 다음 단계 → 미래 단계)
  - 단계별 주간 미션 (각 4개)
  - 미션 체크박스 기반 완료 처리
  - ProgressCircle로 단계별 진행률 시각화
  - P1 스포츠 5개 로드맵 smoke test PASS 확인
- **사업계획서 활용 포인트**: 직업 탐색에서 끝나지 않고, 단계별 실천 미션을 통해 진로 경험을 쌓아가는 구조

### 6-8. 명따라 성향 리포트

- **구현 상태**: Phase 1 구현 완료 운영 중, Phase 2 구조 준비 및 비활성
- **사용자 대상**: 학부모 (자녀 성향 참고 자료 확인)
- **주요 화면**: `/myeonddara`, `/myeonddara/result`
- **주요 특징 (Phase 1 — 현재 운영)**:
  - 생년월일, 태어난 시간, 양력/음력, 성별 입력 기반
  - 만세력 계산 결과 기반 성향 참고 리포트
  - 4주 카드, 오행 분포, 기질 키워드, 부모 관찰 포인트, 학습 스타일, 부모 가이드 팁 제공
  - API 미호출 — 빠르고 안정적
  - 면책 안내 문구 포함
- **설계 원칙**: 아이의 진로를 단정하거나 결정하지 않음. 부모와 자녀의 진로 대화를 시작하는 참고 자료로 설계
- **Phase 2**: OpenAI 기반 고도화 분석 구조는 준비되어 있으나, 베타 안정성을 위해 현재 비활성 유지
- **사업계획서 활용 포인트**: 동양 철학 기반 성향 참고 자료를 AI 서비스와 결합한 차별화된 진로 탐색 도구
- **확인 파일**: `src/app/myeonddara/result/page.tsx`, `docs/myeonddara-beta-design.md`

### 6-9. 명따라 결과 → 관심 운동 추천 연결

- **구현 상태**: 구현 완료 (2026-05-27)
- **주요 특징**:
  - 명따라 결과 화면 하단에 관심 운동 진로 탐색 CTA 카드 표시
  - 성향 참고 리포트 확인 후 `/explore/interests/sports`로 자연스럽게 이동
  - Phase 1 / Phase 2 공통 표시 — DB·API 변경 없이 구현
- **사업계획서 활용 포인트**: 서비스 내 기능 간 자연스러운 연결 흐름으로 사용자 탐색 경험 확장

### 6-10. AI 진로 상담

- **구현 상태**: 구현 완료, 베타 운영 중
- **사용자 대상**: 학부모
- **주요 화면**: `/parent/counseling`
- **주요 특징**:
  - OpenAI GPT-4o-mini 기반 대화형 AI 상담
  - 무료(free): 월 3회, 유료 플랜: 월 30~200회 (플랜별 차등)
  - 학부모 대상 자녀 진로 관련 질문에 대한 대화형 안내
  - 추천 질문 칩 제공 (입력창 자동 채움)
  - Feature flag(`AI_CONSULT_ENABLED`)로 제어 — 현재 활성 상태
- **설계 원칙**: 결과 보장형 표현 금지, 진로 탐색 준비·설계형 대화 중심
- **사업계획서 활용 포인트**: 학부모의 자녀 진로 고민을 실시간으로 도와주는 AI 보조 도구
- **확인 파일**: `src/app/parent/counseling/page.tsx`, `src/lib/featureFlags.ts`

### 6-11. 부모 주간 리포트 베타

- **구현 상태**: 베타 구현 완료
- **사용자 대상**: 학부모
- **주요 화면**: `/report`
- **주요 특징**:
  - 자녀의 로드맵 진행 상황 확인
  - 지난주 vs 이번주 실천 미션 비교 막대 그래프
  - 추천 활동 완료 저장 및 관리
  - 주간 단위 진로 활동 변화 시각화
- **사업계획서 활용 포인트**: 단발성 탐색으로 끝나지 않고 학부모가 자녀의 진로 탐색 흐름을 주간 단위로 확인하고 관리하는 구조

## 7. AI 활용 현황

AI 활용 현황은 현재 운영 상태 기준으로 정직하게 정리한다.

| 구분 | 현재 상태 | 설명 |
|---|---|---|
| AI 진로 상담 | 운영 중 (베타) | OpenAI GPT-4o-mini 기반. 학부모 대상 자녀 진로 관련 대화형 상담. 무료 월 3회, 유료 플랜별 차등 제공. |
| 명따라 Phase 1 | 운영 중 | API 미호출. 만세력 계산 기반 규칙형 성향 참고 리포트 제공. |
| 명따라 Phase 2 | 비활성 | OpenAI 기반 고도화 분석 구조 준비 완료. 베타 안정성을 위해 현재 비활성 유지. |
| AI 결과 활용 원칙 | 참고용 | 진로 결정이나 예측이 아닌 학부모-자녀 대화와 탐색을 돕는 참고 자료로 설계. |
| Feature flag 제어 | 완료 | AI 관련 기능은 모두 Feature flag로 활성/비활성 전환 가능. 베타 안정성 확보. |
| 사용량 차감 정책 | 차감 유예 | 명따라 Phase 2 베타 기간 중 연간 횟수 차감 유예. AI 상담은 플랜별 월 횟수 관리. |
| 면책 안내 | 포함 | AI 및 명따라 결과 화면에 "참고용 자료" 면책 안내 필수 포함. |

### AI 활용 설계 원칙

꿈따라의 AI는 아이의 진로를 단정하거나 최적 직업을 확정하는 도구가 아니다. 학부모와 자녀가 진로 대화를 시작하고 탐색의 폭을 넓힐 수 있도록 돕는 **보조 참고 도구**로 설계되어 있다.

- AI 진로 상담: 학부모의 자녀 진로 고민에 대화형으로 안내하는 보조 도구
- 명따라: 만세력 기반 성향 키워드를 참고 자료로 제공. AI 분석(Phase 2)은 구조만 준비되어 있으며 현재 비활성
- 모든 AI 결과물에 "참고 자료" 성격을 명확히 안내하는 면책 문구 포함

## 8. 데이터 활용 현황

| 데이터 | 활용 목적 | 현재 상태 |
|---|---|---|
| 직업 데이터 (occupation_master) | 직업 탐색 및 상세 페이지 구성 | 대표 직업 100개 + 세부 직업 14개 = 114개 관리 중 |

| 자녀 프로필 데이터 (child) | 자녀 관심사·학년 기반 맞춤 탐색 | DB 기반, 학부모 계정에 종속 |
| 관심 직업 데이터 (liked_occupations) | 관심 직업 저장 및 필터 | 로그인 시 DB, 비로그인 시 localStorage fallback |

| 명따라 사용량 (myeonddara_usage) | 연간 사용 횟수 관리 | DB 기반, Phase 2 활성화 전까지 차감 유예 |
| AI 상담 사용량 (ai_consult_usage) | 월별 AI 상담 횟수 관리 | DB 기반, 플랜별 월 한도 관리 |

### 데이터 처리 원칙

- 자녀 정보는 부모 계정에 종속되어 부모의 동의 하에 처리
- 자녀 정보는 진로 탐색, 미션 제공, 부모 리포트 생성 목적으로만 사용
- 광고·마케팅 목적으로 자녀 정보를 활용하거나 제3자에게 제공하지 않음
- 개인정보처리방침에 명시된 항목만 수집 (제1조~제3조 준수)

## 9. 공공데이터 활용 가능성

### 현재 구현 상태

현재 꿈따라는 내부 직업 데이터와 사용자 활동 기반 진로 탐색 구조를 중심으로 구현되어 있다. 외부 공공데이터와의 실시간 연동은 아직 구현되지 않았다.

- occupation_master: 오즈케이랩 내부에서 직접 구성한 직업 데이터
- sportsInterestData: 스포츠 관심사 기반 직업 연결 데이터 (내부 구성)
- roadmaps.ts: 직업별 단계별 진로 경험 데이터 (내부 구성)

### 향후 공공데이터 연계 가능성

꿈따라의 직업 탐색 구조는 공공데이터 연계를 통해 다음과 같이 서비스 범위를 확장할 수 있다.

| 공공데이터 | 활용 가능성 | 기대 효과 |
|---|---|---|
| 한국직업정보 (워크넷, 직업정보 공공 API) | 직업별 전망·임금·직무 정보 연계 | 직업 상세 페이지 정보 풍부화 |
| 직업진로정보망 (커리어넷) | 직업 설명, 관련 학과 정보 연계 | 학부모·학생 신뢰도 높은 정보 제공 |
| 경기도 진로체험처 데이터 | 지역별 진로 체험 기관 정보 연계 | 지역 기반 오프라인 진로 체험 연결 |
| 경기도 교육기관 데이터 | 학교, 학원, 교육기관 위치 정보 | 근처 진로 교육 기관 연결 |
| 경기도 청소년 지원사업 데이터 | 지자체 청소년 진로지원 프로그램 | 꿈따라 이용자에게 지역 프로그램 안내 |
| 고용 전망 통계 (통계청, 고용정보원) | 직업별 미래 고용 전망 데이터 | 직업 선택 참고 정보 강화 |
| 학교 진로교육 현황 (교육부) | 학교별 진로교육 현황 데이터 | 학교 연계 B2B 서비스 근거 자료 |

현재 꿈따라는 내부 직업 데이터와 사용자 활동 기반 진로 탐색 구조를 중심으로 구현되어 있으며, 향후 공공 직업 정보, 경기도 지역 진로체험처, 청소년 교육지원 사업 데이터와 연계해 지역 기반 진로 추천 서비스로 확장할 수 있다.

## 10. 사용자 이용 흐름

### 흐름 1. 학생·학부모 공통 직업 탐색 흐름

```
랜딩 페이지 (/)
→ 회원가입 / 로그인
→ 직업 탐색 (/explore)
→ 관심 분야 카테고리 선택 또는 직업명 검색
→ 직업 카드 클릭 → 직업 상세 페이지 (/explore/[id])
→ 직업 상세 내용 및 연관 직업 확인
→ 로드맵 보기 (/roadmap/[occupationId])
→ 3단계 로드맵 확인
→ 주간 미션 체크
→ 진행률 확인
```

### 흐름 2. 관심 운동 기반 진로 탐색 흐름

```
직업 탐색 (/explore) 또는 명따라 결과 화면
→ "관심 운동으로 진로 보기" CTA 선택
→ 관심 운동 선택 화면 (/explore/interests/sports)
→ 10개 운동 중 좋아하는 운동 선택 (축구, 야구, 수영, 줄넘기 등)
→ 선택한 운동과 연결된 직업 목록 및 연결 이유 확인
→ 직업 상세 보기 → 직업 상세 페이지로 이동
→ 로드맵 또는 추가 탐색 계속
```

### 흐름 3. 명따라 성향 리포트 흐름

```
학부모 홈 (/parent/home) → 명따라 카드 선택
→ 명따라 진입 (/myeonddara)
→ 자녀 선택 + 생년월일·시간·양력음력·성별 입력
→ "명따라 리포트 보기" 버튼 클릭
→ 만세력 계산 → 성향 참고 리포트 표시 (/myeonddara/result)
  - 4주 카드, 오행 분포, 기질 키워드, 부모 관찰 포인트, 학습 스타일, 부모 가이드 팁 확인
→ "관심 운동으로 진로를 더 넓게 살펴보세요" CTA 확인
→ 관심 운동 기반 진로 탐색으로 자연스러운 이동
→ 다시 분석하기 또는 직업 탐색 계속
```

### 흐름 4. 부모 주간 리포트 흐름

```
학부모 홈 (/parent/home) → 리포트 카드 선택
→ 주간 리포트 (/report)
→ 자녀의 이번 주 진로 활동 현황 확인
→ 지난주 vs 이번주 미션 실천 비교 그래프 확인
→ 주간 미션 진행률 확인
→ 자녀와 진로 대화 시작
```

### 흐름 5. AI 진로 상담 흐름

```
학부모 홈 (/parent/home) → AI 상담 카드 선택
→ AI 상담 화면 (/parent/counseling)
→ 추천 질문 칩 선택 또는 직접 질문 입력
→ GPT-4o-mini 기반 대화형 진로 상담 진행
→ 답변 확인 및 추가 질문
→ (유료 플랜) 대화 이어가기 지원
```

## 13. 사업계획서에 활용 가능한 강점 문구

아래 문구는 사업계획서에 직접 복사해서 사용할 수 있도록 작성되었다.

1. **서비스 가치 정의**  
   꿈따라는 아이의 관심사와 성향을 출발점으로 직업 탐색, 로드맵, 주간 미션을 연결해 진로 탐색을 실행 가능한 경험으로 전환하는 서비스다.

2. **관심 운동 기반 진로 탐색**  
   관심 운동 기반 진로 탐색 기능은 축구·수영·줄넘기 등 아이가 좋아하는 활동을 스포츠 산업 생태계의 다양한 직업과 연결한다. 아이가 꿈꾸는 스포츠 관련 진로가 선수에 국한되지 않도록, 스포츠 데이터 분석가·유소년 지도자·운동처방사 등 생태계 전반의 직업을 탐색할 수 있다.

3. **명따라 리포트 설계 원칙**  
   명따라 리포트는 자녀의 성향을 단정하거나 진로를 확정하지 않고, 학부모와 자녀가 진로 대화를 시작할 수 있는 참고 자료로 설계되어 있다.

4. **로드맵과 미션 구조**  
   꿈따라는 직업 탐색 이후 단계별 로드맵과 주간 실천 미션을 통해 탐색을 일회성 이벤트가 아닌 지속적인 진로 경험으로 연결한다.

5. **AI 활용 원칙**  
   AI 진로 상담 및 명따라 분석은 아이의 진로를 확정하거나 예측하는 도구가 아니라, 학부모와 자녀의 진로 대화를 돕는 보조 참고 도구로 설계되어 있다.

6. **스포츠 산업 생태계 관점**  
   꿈따라의 스포츠 진로 탐색은 선수가 되는 것만이 스포츠 관련 진로라는 편견에서 벗어나, 스포츠 콘텐츠 기획·데이터 분석·안전 관리·운동처방 등 스포츠 산업 전반의 다양한 직업 세계를 탐색하도록 설계되어 있다.

7. **B2B 확장 가능성**  
   꿈따라의 직업 탐색 및 로드맵 구조는 학교 진로 수업, 학원 상담 자료, 지자체 청소년 진로 지원 프로그램 등 다양한 기관에서 활용 가능한 B2B 진로 도구로 확장이 가능하다.

8. **공공데이터 연계 확장성**  
   현재 꿈따라는 내부 직업 데이터 기반으로 운영 중이며, 향후 경기도 지역 진로체험처, 청소년 교육지원 사업, 공공 직업 정보 데이터와 연계해 지역 기반 진로 추천 서비스로 확장할 수 있다.

9. **베타 단계 안전 운영**  
   꿈따라는 베타 단계에서 TypeScript 검사 및 Production build 통과, smoke test 기반 기능 검증, 면책 안내 문구 포함, Feature flag 기반 AI 기능 통제 등 안전한 운영 기준을 유지하고 있다.

10. **사용자 흐름 연결 설계**  
    명따라 성향 참고 리포트 → 관심 운동 진로 탐색 → 직업 상세 → 로드맵 → 주간 미션으로 이어지는 단계별 진로 탐색 흐름을 서비스 내에서 자연스럽게 연결하는 구조를 갖추고 있다.

11. **부모 주간 리포트**  
    꿈따라는 학부모가 자녀의 진로 탐색 진행 상황을 주간 단위로 확인하고, 지난주 대비 이번 주 미션 실천 변화를 비교할 수 있는 부모 주간 리포트를 제공한다.

12. **진로 대화 지원 설계**  
    꿈따라의 모든 기능은 진로를 결정해주는 것이 아니라, 학부모와 자녀가 진로를 함께 이야기할 수 있는 대화의 시작점과 탐색 도구를 제공하는 방향으로 설계되어 있다.
