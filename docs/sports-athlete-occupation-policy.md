## 1. 작업 목적

꿈따라 프로젝트에서 `축구선수`, `야구선수`, `줄넘기 선수` 같은 운동선수 직업군을 실제 `occupation_master`에 추가할지 여부를 검토하고 정책 방향을 결정한다.

이 문서는 **정책 검토 문서**다.

- 코드를 구현하지 않는다.
- DB를 변경하지 않는다.
- migration을 작성하지 않는다.
- 신규 직업을 insert하지 않는다.

## 3. 운동 종목, 대표 꿈, 실제 직업의 구분

꿈따라에서 아이의 관심 운동은 세 가지 레이어로 구분한다.

| 레이어 | 예시 | 처리 방식 |
|---|---|---|
| 관심 운동 (종목) | 축구, 야구, 줄넘기, 수영 | 직업이 아니라 **진로 탐색의 출발점**. `occupation_master`에 넣지 않음 |
| 대표 꿈 (운동선수 계열) | 축구선수, 야구선수, 줄넘기 선수 | `sportsInterestData.ts`의 `representativeDream` 텍스트로만 표시. 현재 직업 카드 없음 |
| 연결 직업군 | 스포츠 데이터 분석가, 유소년 스포츠 지도자, 운동처방사 | 실제 `occupation_master` 직업. `/explore/[id]`로 링크 연결 가능 |

이 구분 원칙은 꿈따라 전반에서 유지한다:
- 운동 종목명 자체(`축구`, `야구`, `줄넘기`)는 직업이 아니다.
- 운동선수(`축구선수`, `야구선수`)는 **아직 직업 카드가 없는 대표 꿈 텍스트**다.
- 연결 직업군만 실제 `occupation_master`에 존재하는 slug로 관리한다.

## 4. 운동선수 직업군 후보 목록

| 운동선수 직업 | 현재 상태 | 비고 |
|---|---|---|
| 축구선수 | ❌ 미추가 | 관심 운동 `soccer`의 대표 꿈 |
| 야구선수 | ❌ 미추가 | 관심 운동 `baseball`의 대표 꿈 |
| 농구선수 | ❌ 미추가 | 관심 운동 `basketball`의 대표 꿈 |
| 배구선수 | ❌ 미추가 | 관심 운동 `volleyball`의 대표 꿈 |
| 수영선수 | ❌ 미추가 | 관심 운동 `swimming`의 대표 꿈 |
| 태권도 선수 | ❌ 미추가 | 관심 운동 `taekwondo-martial-arts`의 대표 꿈 |
| 줄넘기 선수 | ❌ 미추가 | 육상선수 대신 포함 결정. 방과후·학교 체육 연결성 기준 |
| 골프선수 | ❌ 미추가 | 관심 운동 `golf`의 대표 꿈 |
| e스포츠 선수 | ❌ 미추가 | 표현 주의 필요 (게임 중독 연상 배제) |

**제외 결정:**
- `육상선수`: 초등학생 일상 스포츠보다 엘리트·경쟁 트랙 이미지가 강함. 방과후·학교 체육과의 연결성이 낮음.

**포함 결정:**
- `줄넘기 선수`: 초등 접근성 높음. 음악줄넘기, 리듬줄넘기, 방과후 활동, 유소년 스포츠 지도, 운동처방, 스포츠 콘텐츠와 연결 가능.

## 5. A안: 운동선수 직업군 미추가 유지

### 내용

- 축구선수, 야구선수, 줄넘기 선수 등은 `occupation_master`에 추가하지 않는다.
- `sportsInterestData.ts`의 `representativeDream` 텍스트로만 유지한다.
- 관심 운동 선택 화면(`/explore/interests/sports`)에서 대표 꿈 텍스트로 보여준다.
- 실제 연결 직업은 스포츠 데이터 분석가, 유소년 스포츠 지도자, 운동처방사 등 기존 직업으로 안내한다.

### 장점

- DB 변경 없음 — 현 단계 개발 리소스를 다른 곳에 집중 가능
- 대표 직업 100개 체계 유지 — 기존 카테고리 균형 유지
- 선수 중심으로 진로가 좁아지는 문제를 줄일 수 있음
- "운동을 좋아한다고 꼭 선수만 길은 아니다"는 핵심 메시지 강화 가능
- 운동선수 직업을 추가하지 않아도 관심 운동 → 연결 직업 흐름은 이미 구현 완료 상태

### 단점

- 아이가 `/explore`에서 `축구선수`를 검색했을 때 직접 직업 카드가 없어 보일 수 있음
- 운동선수를 꿈꾸는 아이에게는 직관성이 낮을 수 있음
- "이 꿈이 꿈따라에는 없다"는 느낌을 줄 수 있음

### 보완 방법

- 검색 UX 보완: `축구선수`, `줄넘기 선수` 검색 시 관심 운동 안내 블록과 연결 직업군 표시
- `/explore/interests/sports` 진입 유도 CTA 강화

## 6. B안: 운동선수 직업군 일부 추가

### 내용

- 축구선수, 야구선수, 수영선수, 태권도 선수, 줄넘기 선수 등 일부만 추가한다.
- 대표 직업 100개 이후 확장 직업으로 관리한다.
- 관련 summary, preparations, quizData, goyo24_profile 또는 manual profile, roadmap/fallback까지 별도 작성한다.

### 장점

- 아이들이 직관적으로 이해하기 쉬움
- `축구선수`, `줄넘기 선수` 검색 시 직접 노출 가능
- 관심 운동 선택 화면과 직업 상세 연결이 자연스러워짐

### 단점

- occupation_master 총량 증가 — 현재 114개에서 추가됨
- 선수 직업이 과도하게 늘어날 수 있음
- 프로선수 중심 사고가 강화될 수 있음 (진로 탐색 목적과 반대 방향)
- 표준 세트(summary 3종 + preparations 3종 + quizData 3문항 + goyo24_profile) 작업량이 큼
- 운동선수 직업의 현실적인 임금·전망 데이터가 극소수를 제외하면 공개 통계가 제한적

### 추가 시 발생하는 작업량 (종목별)

| 작업 항목 | 직업당 필요 작업 |
|---|---|
| occupation_master | 1 row |
| occupation_summary | 3 rows (one_liner, easy_description, why_this_job) |
| occupation_preparations | 3 rows (mission_hint × 1, step_action × 2) |
| quizData | 3문항 |
| occupation_goyo24_profile | 1 row (source='manual') |
| 관심 운동 연결 | careerLink 추가 (sportsInterestData.ts 수정) |
| smoke test | URL 확인 |

9개 종목 전부 추가 시 최소 9 × 7 작업 = 63개 항목 + quizData 27문항.

## 7. C안: 별도 구조 관리

### 내용

- 운동선수 직업군을 `occupation_master`에 바로 넣지 않는다.
- 장기적으로 `interest_sports`, `sport_athlete_examples`, `sport_career_links` 같은 별도 구조에서 관리한다.
- 현재는 `representativeDream` 텍스트와 검색 UX 보완으로 처리한다.

### 예시 스키마 (미구현, 설계 참고용)

```sql
-- 운동선수 대표 꿈 별도 관리
sport_athlete_examples
  sport_slug       text    -- 관심 운동 slug (soccer, jump-rope 등)
  athlete_name_ko  text    -- 예: 축구선수, 줄넘기 선수
  athlete_slug     text    -- 향후 occupation_master 연결 시 사용 (현재 null)
  note             text    -- 설명 문구
```

### 장점

- 운동 종목과 직업의 구분이 명확함
- 장기 확장성이 좋음
- 관심 운동 기반 추천 구조와 잘 맞음
- 운동선수 꿈을 유지하면서도 연결 직업군을 넓게 보여줄 수 있음

### 단점

- 당장 직업 검색 결과에 운동선수 카드가 나오지는 않음
- 별도 구조 구현이 필요함 — 현 MVP 단계에서 과도한 설계일 수 있음

## 8. 검색 UX 보완 필요성

현재 `/explore` 검색창에서 `축구선수`, `줄넘기 선수`, `야구선수`를 입력하면 **검색 결과가 비어 보인다.**

이것이 A안의 핵심 단점이다. 아이와 학부모 입장에서 "꿈따라에는 이 직업이 없구나"라고 느낄 수 있다.

### 현재 검색 로직 (explore/page.tsx)

```ts
const matchSearch =
  !isSearching ||
  occ.name.includes(q) ||
  occ.description.includes(q) ||
  occ.skills.some((s) => s.includes(q));
```

- `occ.name`: 직업명 (`스포츠 데이터 분석가` 등)
- `occ.description`: one_liner
- `occ.skills`: interest_fields 배열

`축구선수`라는 단어는 현재 어느 직업의 name/description/skills에도 없으므로 검색 결과가 빈다.

### 보완 방향 (다음 작업지시서)

| 보완 방법 | 내용 | 우선순위 |
|---|---|---|
| 관심 운동 키워드 안내 블록 | 검색어가 운동선수 관련 키워드일 때 `/explore/interests/sports` 진입 CTA 표시 | ✅ 추천 (A안 보완) |
| interest_fields 키워드 추가 | 기존 스포츠 진로 직업의 `interest_fields`에 `축구`, `야구`, `줄넘기` 등 키워드 추가 | 검토 |
| aliases 필드 추가 | `occupation_master`에 `search_aliases` 필드를 추가하여 `축구선수 → 스포츠 데이터 분석가` 연결 | 장기 |
| one_liner/easy_description에 종목 언급 | 기존 직업 설명에 관심 종목 키워드를 자연스럽게 포함 | 장기 |

**1차 권장:** 검색어가 `축구`, `축구선수`, `야구`, `야구선수`, `줄넘기`, `줄넘기 선수` 등일 때, 검색 빈 결과 화면 대신 관심 운동 탐색 CTA 블록을 표시한다.

## 9. 1차 권장 결론

```text
현 단계에서는 운동선수 직업군을 occupation_master에 바로 추가하지 않는다.

축구선수, 야구선수, 줄넘기 선수 등은 관심 운동의 대표 꿈 텍스트로 유지한다.

대신 /explore 검색에서 축구, 축구선수, 줄넘기, 줄넘기 선수 같은 키워드를 입력했을 때
관심 운동 안내 블록과 연결 직업군을 보여주어 "검색했는데 아무것도 없는 느낌"을 줄인다.

운동선수 직업군 추가는 실제 사용자 반응을 확인한 뒤 별도 확장 작업으로 결정한다.
```

**1차 권장안: A안 + 검색 UX 보완**

| 항목 | 결정 |
|---|---|
| occupation_master 즉시 추가 여부 | ❌ 미추가 유지 |
| 대표 꿈 처리 | representativeDream 텍스트로만 표시 |
| 검색 처리 | 관심 운동 키워드 검색 시 CTA 안내 블록 표시 (다음 작업) |
| 줄넘기 선수 처리 | 대표 꿈 텍스트 유지. 육상선수 대신 포함. |
| 육상선수 처리 | 제외 (초등 일상 접근성 낮음) |
| 후속 검토 | 실제 사용자 반응 확인 후 B안 또는 C안 결정 |

### 결론 근거

1. **대표 직업 100개 체계 유지:** 현재 occupation_master 114개로 대표 직업 100개 달성. 운동선수 직업을 추가하면 카테고리 균형이 무너질 수 있음.
2. **핵심 메시지 보호:** 꿈따라의 핵심 메시지는 "운동을 좋아한다고 꼭 선수만 길은 아니다". 운동선수 직업을 직접 추가하면 이 메시지가 약해질 수 있음.
3. **작업량 대비 효과:** 9개 종목 × 7개 항목 + quizData 27문항 = 상당한 작업량. 실제 사용자 수요 확인 전에는 투자 대비 효과가 불명확.
4. **현재 구현으로 충분:** 관심 운동 선택 화면(`/explore/interests/sports`)과 연결 직업 섹션이 이미 구현되어 있어, 검색 UX 보완만으로도 경험을 개선할 수 있음.
