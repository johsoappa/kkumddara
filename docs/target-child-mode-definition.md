# 꿈따라 자녀 타겟층·모드 기준

> 확정일: 2026-06-09
> 본 문서가 꿈따라 자녀 타겟층/모드 기준의 **최신 표준(source of truth)** 입니다.
> 과거 docs(ROADMAP, billing-readiness 등)에 남은 `초3~중2`, `초5~중3` 등은 이력 기록이며, 화면·정책은 본 기준을 따릅니다.

## 1. 확정 기준

- 🌱 씨앗모드: 초1~초2 (7~9세)
- 🌿 새싹모드: 초3~초4 (10~11세)
- 🧭 나침반모드: 초5~고등 (12~18세)

## 2. 모드별 목적

### 🌱 씨앗모드 (초1~초2)
직업 세계와 첫 만남, 흥미의 씨앗 발견

### 🌿 새싹모드 (초3~초4)
반복 활동으로 재능과 가능성 확장

### 🧭 나침반모드 (초5~고등)
관심 분야와 강점으로 진로 방향 설계

## 3. 제품 적용 원칙

- 씨앗모드는 쉽고 재미있는 직업 탐색, 놀이형 미션, 가벼운 부모 대화 중심
- 새싹모드는 반복 활동, 관심 패턴 확인, 직업군 탐색, 부모 관찰 질문 중심
- 나침반모드는 관심 분야, 강점, 직업 전망, 관련 과목·계열 고민으로 확장
- 모든 모드는 진로 단정이 아니라, 부모와 아이가 함께 대화하는 출발점으로 설계

## 4. 카피 기준

### 대표 설명 (기본)
```

아이의 관심이 자라고 진로 방향이 잡히는 과정을
부모와 함께 기록하는 진로 탐색 서비스입니다.
```

### 대표 설명 (짧은 버전)
```

```

## 5. 금지 표현

- "진로를 결정한다" / "적성을 확정한다" / "사주로 직업을 맞힌다"
- "검사 중심" / "진단" / "보장" 등 단정·확정 표현
- 꿈따라의 핵심 포지션은 **관심 기반 진로 탐색·기록·대화·작은 실천**
