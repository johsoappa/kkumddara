# 꿈따라 베타 피드백·문의·오류 기록 템플릿

> 작성일: 2026-05-30  
> 목적: 베타 사용자 피드백, 문의, 오류 제보를 일관되게 기록하고 분류하기 위한 운영 템플릿  
> 사용 방법: 이 문서를 복사해 피드백을 받을 때마다 섹션별로 기록한다.

---

## 1. 문서 목적

- 베타 사용자 피드백을 흩어지지 않게 관리
- 문의 / 오류 / 개선 제안 / 정책 질문을 구분
- P0 / P1 / P2 / P3 우선순위 판단 기준 마련
- 향후 기능 개선 작업지시서 작성의 기준 자료 확보
- 결제 오픈 전 정책 확정에 필요한 실제 사용자 반응 축적

---

## 2. 사용 시점

아래 상황에서 이 문서의 템플릿을 사용한다:

- 지인 5명 제한 베타 공유 후 피드백을 받을 때
- 카카오채널 또는 이메일로 문의가 들어올 때
- 오류 제보를 받을 때
- 베타 사용자와 대화 후 의견을 정리할 때
- 주간 운영 체크리스트 작성 시

---

## 3. 기록 원칙

1. 감정적 평가보다 개선 판단이 가능한 구체적 내용을 기록한다.
2. 추정이 아닌 실제 사용자가 한 말이나 행동을 기준으로 적는다.
3. P0 발견 시 즉시 작업지시서를 작성한다.
4. 반복되는 피드백은 별도 표시한다 (동일 의견 2회 이상).
5. 정책 미확정 항목은 임의로 답변하지 않는다.

---

## 4. 피드백 분류 기준

| 분류 | 의미 | 예시 |
|---|---|---|
| 문의 | 사용자가 기능이나 정책을 이해하지 못해 질문한 경우 | 명따라는 몇 번 쓸 수 있나요? |
| 오류 | 기능이 의도대로 동작하지 않는 경우 | 버튼 클릭 시 홈으로 이동함 |
| 개선 제안 | 동작은 정상이나 더 나은 UX 제안이 있는 경우 | 아이가 보기엔 문구가 어렵다 |
| 정책 질문 | 요금제, 결제, 사용량, 환불 등 운영 기준 질문 | 유료 플랜은 언제 시작하나요? |
| 콘텐츠 피드백 | 직업 설명, 로드맵, 문구, 추천 결과 관련 의견 | 이 직업 설명이 너무 어렵다 |
| 긍정 피드백 | 유지할 가치가 있는 좋은 반응 | 아이가 관심 운동 탐색을 좋아했다 |

## 5. 이슈 우선순위 기준

| 우선순위 | 기준 | 예시 | 대응 기준 |
|---|---|---|---|
| P0 | 베타 사용 자체가 막히거나 신뢰를 크게 훼손하는 문제 | 로그인 불가, 홈 진입 불가, 개인정보 노출 의심 | 즉시 수정 후보 |
| P1 | 주요 기능 사용 흐름에 영향을 주는 문제 | 명따라 결과 미표시, 로드맵 저장 오류, 잘못된 정책 문구 | 다음 작업지시서 후보 |
| P2 | 불편하지만 사용은 가능한 문제 | 문구 어색함, 버튼 위치 개선, 설명 추가 필요 | 누적 후 개선 |
| P3 | 아이디어 또는 장기 개선 항목 | 학교용 관리자 기능, 추천 알고리즘 고도화 | 백로그 보관 |

## 11. 기능별 피드백 체크리스트

베타 사용자와 함께 확인하거나, 피드백 수렴 후 기능별로 상태를 정리할 때 사용한다.

### 랜딩 페이지 (`/`)

- [ ] 첫 문장에서 서비스가 무엇인지 이해되는가?
- [ ] "아직 꿈이 없어도 괜찮아요" 메시지가 자연스러운가?
- [ ] 학부모가 신뢰할 수 있는 느낌이 있는가?
- [ ] 버튼 클릭 흐름이 명확한가?
- [ ] 학부모/학생 체험 버튼이 눈에 잘 들어오는가?

### 학부모 체험 (`/demo/parent`)

- [ ] 주간 리포트 / AI 상담 / 명따라 카드 안내가 자연스러운가?
- [ ] 카드 클릭 시 인라인 안내가 이해되는가?
- [ ] 로그인 필요 안내가 부담스럽지 않은가?
- [ ] 베타 무료 이용 문구가 명확한가?
- [ ] 홈으로 튕기는 현상이 없는가?

### 학생 체험 (`/demo/student`)

- [ ] 아이가 직접 눌러보고 싶어 하는가?
- [ ] 문구가 너무 어렵지 않은가?
- [ ] "아직 꿈이 정해지지 않아도 괜찮아요" 서브텍스트가 보이는가?
- [ ] 직업 탐색으로 넘어가는 흐름이 자연스러운가?

### 직업 탐색 (`/explore`)

- [ ] 100개 직업이 충분해 보이는가?
- [ ] 검색 결과가 기대와 맞는가?
- [ ] 세부 직업이 없는 것으로 오해하지 않는가?
- [ ] 카드 설명이 이해하기 쉬운가?
- [ ] 관심 운동 탐색 CTA가 자연스러운가?

- [ ] 운동선수가 아니어도 관련 직업이 있다는 설명이 긍정적으로 느껴지는가?
- [ ] 금지 표현이나 부정적 표현이 없는가?

### 로드맵 미션 (`/roadmap/[id]`)

- [ ] 아이가 실행할 수 있는 작은 미션처럼 보이는가?
- [ ] 부모가 보기에도 실천 가능한 활동인가?
- [ ] 저장/체크 흐름이 어렵지 않은가?
- [ ] 3단계 구조가 이해되는가?

### 명따라 (`/myeonddara`)

- [ ] 참고용 리포트라는 점이 이해되는가?

- [ ] 학부모가 질문을 입력하기 쉬운가?
- [ ] 무료 횟수 제한 안내가 명확한가?

- [ ] 평가표가 아니라 대화 자료로 느껴지는가?
- [ ] 이번주/지난주 비교가 이해되는가?

- [ ] 베타 기간 무료 이용과 자동결제 없음이 명확한가?

- [ ] 유료 플랜의 미확정 항목이 과하게 확정된 것처럼 보이지 않는가?
- [ ] 결제 기능 미오픈 안내가 오해 없이 전달되는가?

## 12. P0 즉시 대응 기준

아래 항목이 발견되면 다른 작업을 멈추고 즉시 수정 작업지시서를 작성한다.

- 로그인 또는 회원가입 불가
- 주요 페이지 접속 불가 (`/explore`, `/roadmap`, `/myeonddara`)
- 자녀 정보가 다른 사용자에게 노출되는 의심
- 명따라 또는 AI 상담 결과에서 위험하거나 부적절한 문구 출력
- 결제 기능 미오픈 상태인데 결제가 발생하는 것처럼 보이는 문구
- 베타 무료 이용과 상충되는 자동결제 문구 노출
- 학부모가 서비스 목적을 완전히 오해할 정도의 핵심 문구 오류
- 모바일에서 핵심 버튼이 보이지 않거나 클릭 불가

## 13. P1 다음 작업 후보 기준

아래 항목은 P1로 분류하고, 다음 주간 정리 시 작업지시서 후보로 올린다.

- 기능은 동작하지만 주요 사용 흐름이 헷갈리는 경우
- 명따라 / AI 상담 / 리포트의 설명 문구가 부족한 경우
- 직업 탐색 검색 결과가 기대와 다르게 보이는 경우
- 학부모 체험에서 로그인 유도 흐름이 어색한 경우
- 학생 체험에서 아이가 무엇을 해야 하는지 모르는 경우
- Free 플랜과 유료 플랜 차이가 모호한 경우
- 공동 양육자, 결제, 환불 등 정책 문의가 반복되는 경우 (3회 이상)
