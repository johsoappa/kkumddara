## 4. 주요 피드백 요약

### 지인1 피드백

**장점**
- 진로 준비 경로를 차근차근 알려주는 점이 도움 됨
- 아이와 해볼 대화 문구가 좋음

**우려**
- 아이들이 직접 잘 활용할지 의문
- 진로를 아직 찾지 못한 아이에게 어필이 약해 보임
- 월요금제를 낼 만한 이점이 아직 약해 보임

**후속 반응**
- "관심사에서 관련 직업을 발견하는 서비스"라는 설명 후 긍정 반응
- → 첫 화면 메시지 개선으로 반영 완료

### 지인2 피드백

- 관심분야별 직업 종류를 알 수 있어 좋음
- 관심 직업 선택 후 무엇을 검색하고 공부해야 하는지 알려주는 점이 좋음
- 체계적으로 관리되는 느낌이 기대됨

## 9. 유료화 및 쿠폰 준비 로드맵

**현재 판단**
- 지금 쿠폰 기능 구현은 하지 않는다
- 카카오채널에 쿠폰 메뉴를 아직 노출하지 않는다
- 정식 오픈 직전 `오픈 혜택` 또는 `채널 친구 혜택` 메뉴로 전환한다
- 내부 결제 시스템 개발 전 쿠폰 DB 구조를 별도 설계한다
- 베타 참여자 명단을 별도로 관리한다

**쿠폰 후보**

| 쿠폰명 | 내용 |
|---|---|
| 베타 참여자 감사 쿠폰 | 베타 참여자 전용 할인 또는 무료 기간 제공 |
| 채널 친구 오픈 쿠폰 | 카카오채널 친구 추가 시 혜택 |
| 첫 달 50% 할인 | 초기 전환율 제고 |
| 7일 무료 체험 | 유료 전환 전 체험 기회 |
| 학기 시작 시즌 쿠폰 | 3월·9월 시즌 마케팅 |
